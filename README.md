# OpenCart Manual Testing Project

## Project Overview

This project focuses on manual testing of the OpenCart e-commerce application to validate selected functionalities and identify defects.

## Scope of Testing

- User Registration
- User Login
- User Logout
- Forgot Password
- Wishlist
- Add to Cart

## Testing Activities

- Test Scenario Identification
- Test Case Design and Execution
- Functional Testing
- Positive and Negative Testing
- Defect Reporting

## Project Documents

- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Requirement Traceability Matrix (RTM)
- Bug Report

## Test Summary

- Defects Identified: 5

## Tools Used

- OpenCart
- XAMPP
- Microsoft Excel

## Project Outcome

This project demonstrates practical knowledge of manual testing, test documentation, test execution, and defect reporting.
